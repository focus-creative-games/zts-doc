# FAQ

**Q: 运行时执行 TypeScript 吗？**  
A: 否。只跑 emit 后的 JS（ESM）。

**Q: 和 ZLua 能混用吗？**  
A: 可同工程并存（不同 AppDomain 门面），语义对齐但 VM 不同。

**Q: Demo 打不开？**  
A: Check a supported Unity / Tuanjie version (see [Compatibility](/docs/getting-started/compatibility/)), package `file:` path, and Node (ts-demo only).
